# Python Basics for Data Science

A comprehensive collection of Jupyter Notebooks covering essential Python concepts for data science.

## 📚 Topics Covered

1. **Python Fundamentals** - Variables, data types, operators, and control flow
2. **Data Structures & Functions** - Lists, dictionaries, tuples, sets, and function definitions
3. **Object-Oriented Programming (OOP)** - Classes, inheritance, polymorphism, and encapsulation
4. **File Handling, Serialization & Deserialization** - Working with files, JSON, CSV, and data formats
5. **Exception Handling** - Error management, try-except blocks, and custom exceptions
6. **Namespaces & Decorators** - Scope, namespaces, and function decorators
7. **Extra Topics** - Additional topics like recursion, iterators and generators, git

## 🚀 Quick Start

### Requirements
- Python 3.x
- Jupyter Notebook or JupyterLab

### Installation

```bash
# Install Jupyter
pip install jupyter

# Optional: Install common data science libraries
pip install numpy pandas matplotlib
```

### Running the Notebooks

```bash
jupyter notebook
```

Navigate to any `.ipynb` file and start learning!

## 📖 Structure

Each section is organized as a folder containing related Jupyter notebooks with:
- Concept explanations
- Code examples
- Practice exercises
