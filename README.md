# Python Basics for Data Science

A curated collection of Jupyter Notebooks and resources to learn core Python concepts used in data science. The repository focuses on hands-on examples, exercises, and small projects to help learners build practical skills.

## Contents

- 1. Python fundamentals/ — Basic syntax, variables, control flow, and small examples
- 2. Data structures and Python functions/ — Lists, tuples, dictionaries, sets, and function usage
- 3. OOP/ — Classes, inheritance, and object-oriented design examples
- 5. File handling, serialization, deserialization/ — Working with files, CSV, JSON, and serialization
- 6. Exception handling/ — Error handling patterns and custom exceptions
- 7. Namespace and Decorators/ — Namespaces, scopes, and decorator examples
- 8. Simple python projects/ — Small projects and exercises to practice concepts
- 9. Questions/ — Practice questions and interview-style problems
- Extra topics/ — Additional notes: recursion, iterators, generators, git commands
- Python Interview Questions.pdf — A downloadable PDF with common interview questions and answers

> Note: This repository is primarily Jupyter Notebooks (≈98%) with a small amount of Python scripts.

## Quick start

Requirements
- Python 3.8+ (3.10+ recommended)
- pip
- Jupyter Notebook or JupyterLab

Install (recommended inside a virtual environment)

```bash
# create and activate a virtual environment (recommended)
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1

# install Jupyter and common libraries
pip install --upgrade pip
pip install jupyterlab jupyter numpy pandas matplotlib seaborn
```

Running the notebooks

```bash
# start Jupyter Notebook (opens in the browser)
jupyter notebook
# or start JupyterLab
jupyter lab
```

Open any `.ipynb` file in the browser and run the cells.

## How this repo is organized

Each numbered folder focuses on a topic and contains notebooks with:
- Concept explanations and short theory
- Worked code examples
- Exercises / practice problems

Start with `1. Python fundamentals` and proceed in order, or jump to topics you need to review.

## Recommendations

- Use JupyterLab for an improved notebook experience.
- Run notebooks in a virtual environment to avoid dependency conflicts.
- If you plan to use the notebooks in a course or share them, consider exporting important notebooks to HTML or PDF.
